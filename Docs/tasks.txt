База и драгоценности

[+]2.8 Создать объект EnemySpawner — зона спавна врагов на краю карты.

[+]2.10 ИИ врага 
    [+]2.10.1 idle - Раз в 0.5с сканирует окружение. Ищет ближайший свободный gem на карте (isCarried = false). Если находит — переход в moveToTarget с целью = gem. Если gem нет — остаётся в idle, повторяет скан через 0.5с.
    [+]2.10.2 moveToGem - Враг движется к цели (gem ). Переход в moveToSpawn — подобрал gem (OnTriggerEnter с gem). 
        Переход в idle — цель исчезла (gem подобрал другой враг) и новой нет. Переход в stun — скорость Rigidbody2D превысила порог входа.
    [+]2.10.3 moveToSpawn - Враг несёт gem к спавну. При входе в состояние gem выставляет isCarried = true, становится дочерним объектом врага. 
        Переход в idle — достиг спавна, gem уничтожается (потерян). Переход в stun — скорость превысила порог, gem выпадает сразу (isCarried = false, открепить от врага).
    [+]2.10.4 dead - Финальный стейт, выхода нет. Входит когда Health.isDead = true. Дублирует флаг здоровья явным состоянием в AI — чтобы логика смерти была в одном месте. 
        Вызывает Destroy(gameObject).
    [+]2.10.5 Установить NavMeshPlus через Package Manager. Добавить NavMeshSurface на сцену, запечь навмеш для Level_01. Убедиться что враги находят путь от спавна до сокровищ.
    [+]2.10.6 Переписать движение врага: NavMesh даёт путь, AI берёт desiredVelocity и применяет AddForce в том направлении. Transform.position не используется нигде. 
        Проверить что враги огибают стены и препятствия.
    [+]2.10.7 Добавить параметр float poise (0-100) в скрипт врага. Poise влияет на два свойства одновременно: Linear Drag врага и множитель силы тяги AI. При poise ниже 50% тяга = 0.        
    [+]2.10.8 Добавить восстановление poise: каждый кадр poise растёт на recoveryRate умноженный на множитель зависящий от текущей скорости Rigidbody2D. 
        Быстро летит — множитель близок к нулю. Скорость упала — множитель = 1. Формула и пороги подбираются в тесте.
    [+]2.10.9 Добавить урон от волны в poise: при получении силы давления poise снижается пропорционально скорости столкновения. 
    [+]2.10.10 Проверить что idle, moveToTarget, moveToSpawn корректно работают когда poise низкий — намерение есть, тяга не применяется.
    [+]2.10.11 Создать префабы для четырёх типов: скелет, гоблин, орк, огр.
    [+]2.10.13 Добавить спавн на карту. Добавить гемы на карту и способ помнить их список.

Итерация 3 — Уровень и окружение
Карта деревни, статичные препятствия, интерактивные объекты (бочки, телеги). Первый играбельный уровень.
Статичное окружение

[]3.1 Создать префаб Wall: белый прямоугольник, Box Collider 2D, Rigidbody2D Static. Physics Material с небольшим bounce чтобы враги отлетали а не прилипали.
[]3.2 Создать префаб Rock: серый многоугольник, Polygon Collider 2D, Rigidbody2D Static. Форма неровная — враги отлетают под непредсказуемыми углами.
[]3.3 Создать префаб Fence: тонкий прямоугольник, Box Collider 2D Static. Обозначает границы деревни визуально.

Интерактивные объекты
[]3.4 Создать компонент Prop. Поля: float speedThreshold (порог скорости для нанесения урона), bool affectedByWave (реагирует ли на волну игрока). Вешается на все интерактивные объекты.
[]3.5 Создать префаб Barrel: тёмный круг, Rigidbody2D Dynamic (масса ~3), Circle Collider 2D, компонент Prop.
[]3.6 Создать префаб Cart: вытянутый прямоугольник, Rigidbody2D Dynamic (масса ~5), Box Collider 2D, компонент Prop.
[]3.7 Создать префаб Tree: круг, Rigidbody2D Static, компонент Prop (affectedByWave = false, speedThreshold высокий). При OnCollisionEnter2D с импульсом выше порога — переключается в Dynamic. После падения affectedByWave = true, speedThreshold снижается до обычного — работает как обычный Prop.
[]3.8 В скрипте врага при столкновении: GetComponent Prop на объекте с которым столкнулся. Если компонент есть и скорость выше Prop.speedThreshold — TakeDamage(1).

Структура карты
[]3.9 Создать ScriptableObject MapConfig. Поля: название уровня, массив конфигов волн.
[]3.10 Создать префаб карты Map. Внутри префаба расставить Treasury и EnemySpawner вручную. Скрипт Map хранит ссылки на них, собирает список в OnValidate.
