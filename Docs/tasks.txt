Итерация 1 — Core mechanic (серый бокс)
Трейл за мышью, волна как физический объект, враги-кубы, которых можно толкнуть. Никакого арта — только ощущение механики.

[ ]1.1 Игровое поле
 Создать плоский квад как пол сцены. Добавить Box Collider 2D по четырём краям как стены.
[ ]1.2 Заглушка врага
 Создать префаб Enemy: белый круг, Rigidbody2D (Dynamic, Linear Drag ~2), Circle Collider 2D. Масса = 1. Скриптов нет — просто физический объект.
[ ]1.3 Ручной спавн врагов
 Скрипт SpawnDebug: по нажатию пробела спавнит 5 врагов в случайных точках поля. Только для тестирования.
[ ]1.4 Трейл за мышью
 Создать объект WaterTrail. Скрипт читает позицию мыши через Camera.ScreenToWorldPoint. Trail Renderer рисует след пока зажата ЛКМ. Цвет синий, ширина фиксированная.
[ ]1.5 Сглаженная скорость и масса волны
 В скрипте трейла каждый кадр считать: smoothedSpeed = Lerp(smoothedSpeed, currentDelta.magnitude / Time.deltaTime, 0.1f). Масса волны — инвертированная зависимость от скорости: медленно ведёшь — waveMass растёт. Вывести waveMass в Debug.Log, проверить что значение стабильное а не дёрганое.
[ ]1.6 Сглаженное направление волны
 Каждый кадр пока зажата ЛКМ: smoothedDirection = Vector2.Lerp(smoothedDirection, currentDelta.normalized, 0.2f). Визуализировать через Debug.DrawRay — стрелка должна плавно следовать за движением мыши без рывков.
[ ]1.7 Объект волны — следует за курсором
 Создать префаб Wave: белый эллипс, Rigidbody2D (Kinematic), Collider 2D. При зажатии ЛКМ — спавнится в позиции курсора и каждый кадр перемещается к позиции курсора через MovePosition. Волна существует пока зажата кнопка.
[ ]1.8 Отпускание — волна по инерции
 При отпускании ЛКМ: волна переключается в режим свободного движения. Rigidbody2D получает AddForce в направлении smoothedDirection с силой пропорциональной waveMass. Волна затухает и уничтожается когда скорость упала ниже порога или прошло время.

[ ]1.9 Эксперимент: физика воздействия волны на врагов
 Открытый таск-прототип. Волна должна толкать врагов — но как именно? Попробовать несколько вариантов и выбрать лучший:
OnTriggerEnter2D — разовый импульс при первом касании
OnTriggerStay2D — постоянная сила пока враг внутри волны
Направление силы — строго вперёд по волне, или от центра волны к врагу, или втягивание вслед за волной
Задокументировать что ощущается правильно, зафиксировать выбранный вариант.

1.10 Столкновения врагов между собой
[ ] Проверить что Circle Collider врагов не триггер. Враги при столкновении физически отталкиваются. Подобрать Linear Drag и массу чтобы движение выглядело сочно, не мыльно.
1.11 Детектор удара об стену
[ ] Добавить стенам тег Wall. В скрипте врага OnCollisionEnter2D: если столкнулся с Wall и скорость выше порога — Debug.Log "HIT WALL, speed: X". Урон пока не считаем.
1.12 Разворот волны — взрыв
[ ] В скрипте трейла отслеживать угол между smoothedDirection текущего кадра и предыдущего. Если угол > 120° — Debug.Log "SHARP TURN DETECTED". Само поведение взрыва пока не реализовывать — только детекция.
1.13 Ручное тестирование
[ ] Спавнить 10-15 врагов. Проверить: медленная волна толкает сильнее быстрой, враги толкают друг друга, удар об стену логируется, разворот детектируется. Записать ощущения — это войдёт в правки перед И2.
