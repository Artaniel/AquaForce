Итерация 1 — Core mechanic (серый бокс)
Трейл за мышью, волна как физический объект, враги-кубы, которых можно толкнуть. Никакого арта — только ощущение механики.

[ ]1.1 Игровое поле. Создать плоский квад как пол сцены. Добавить Box Collider 2D по четырём краям как стены.
[ ]1.2 Заглушка врага. Создать префаб Enemy: белый круг, Rigidbody2D (Dynamic, Linear Drag ~2), Circle Collider 2D. Масса = 1. Скриптов нет — просто физический объект.
[ ]1.3 Ручной спавн врагов. Скрипт SpawnDebug: по нажатию пробела спавнит 5 врагов в случайных точках поля. Только для тестирования.
[ ]1.4 Трейл за мышью. Создать объект WaterTrail. Скрипт читает позицию мыши через Camera.ScreenToWorldPoint. Trail Renderer рисует след пока зажата ЛКМ. Цвет синий, ширина фиксированная.
[ ]1.5 Сглаженная скорость и масса волны. В скрипте трейла каждый кадр считать: smoothedSpeed = Lerp(smoothedSpeed, currentDelta.magnitude / Time.deltaTime, 0.1f). Масса волны — инвертированная зависимость от скорости: медленно ведёшь — waveMass растёт. Вывести waveMass в Debug.Log, проверить что значение стабильное а не дёрганое.
[ ]1.6 Сглаженное направление волны. Каждый кадр пока зажата ЛКМ: smoothedDirection = Vector2.Lerp(smoothedDirection, currentDelta.normalized, 0.2f). Визуализировать через Debug.DrawRay — стрелка должна плавно следовать за движением мыши без рывков.
[ ]1.7 Объект волны — следует за курсором. Создать префаб Wave: белый эллипс, Rigidbody2D (Kinematic), Collider 2D. При зажатии ЛКМ — спавнится в позиции курсора и каждый кадр перемещается к позиции курсора через MovePosition. Волна существует пока зажата кнопка.
[ ]1.8 Отпускание — волна по инерции. При отпускании ЛКМ: волна переключается в режим свободного движения. Rigidbody2D получает AddForce в направлении smoothedDirection с силой пропорциональной waveMass. Волна затухает и уничтожается когда скорость упала ниже порога или прошло время.

[ ]1.9 Эксперимент: физика воздействия волны на врагов
 Открытый таск-прототип. Волна должна толкать врагов — но как именно? Попробовать несколько вариантов и выбрать лучший:
OnTriggerEnter2D — разовый импульс при первом касании
OnTriggerStay2D — постоянная сила пока враг внутри волны
Направление силы — строго вперёд по волне, или от центра волны к врагу, или втягивание вслед за волной
Задокументировать что ощущается правильно, зафиксировать выбранный вариант.

[ ]1.10 Столкновения врагов между собой. Проверить что Circle Collider врагов не триггер. Враги при столкновении физически отталкиваются. Подобрать Linear Drag и массу чтобы движение выглядело сочно, не мыльно.
[ ]1.11 Детектор удара об стену. Добавить стенам тег Wall. В скрипте врага OnCollisionEnter2D: если столкнулся с Wall и скорость выше порога — Debug.Log "HIT WALL, speed: X". Урон пока не считаем.
[ ]1.12 Разворот волны — взрыв. В скрипте трейла отслеживать угол между smoothedDirection текущего кадра и предыдущего. Если угол > 120° — Debug.Log "SHARP TURN DETECTED". Само поведение взрыва пока не реализовывать — только детекция.

Итерация 2 — Боевая петля
Здоровье врагов через collision damage, смерть, счётчик, простая win/lose логика. Водоворот.

Здоровье врагов
[]2.1 Добавить скрипт Health. Максимум и текущее значение hp.
[]2.2 Нарисовать индикатор здоровья над врагом: ряд маленьких прямоугольников (простые спрайты). Зелёные = здоровье есть, чёрные = потрачено. Количество прямоугольников = maxHealth.
[]2.3 Добавить кулдаун на получение урона. После каждого хита враг неуязвим N секунд (например 0.3с).
[]2.4 В скрипте врага при столкновении: если скорость столкновения выше порога — вызвать TakeDamage(1). Работает для стен (тег Wall) и для других врагов (тег Enemy).
[]2.5 Добавить зону мгновенной смерти. Триггер-коллайдер с компонентом DeathZone. При касании врагом вызывает смерть.
[]2.6 Добавить смерть от урона. Пока просто Destroy(gameObject) без анимации.
База и драгоценности
[]2.7 Создать префаб Gem: маленький жёлтый ромб, Rigidbody2D (Dynamic, очень лёгкий), Circle Collider 2D. Скрипт Gem: хранит Enemy holder — враг который несёт.
[]2.8 Создать объект Treasury в углу карты. Скрипт Treasury хранит список драгоценностей. При старте уровня спавнит N драгоценностей рядом с собой (N задаётся в инспекторе).
[]2.9 Создать объект EnemySpawner — зона спавна врагов на противоположном краю карты.

[]2.10 ИИ врага 
[]2.10.1 idle - Раз в 0.5с сканирует окружение. Ищет ближайший свободный gem на карте (isCarried = false). Если находит — переход в moveToTarget с целью = gem. Если gem нет — остаётся в idle, повторяет скан через 0.5с.
[]2.10.2 moveToTarget - Враг движется к цели (gem или Treasury если gem нет на карте). Переход в moveToSpawn — подобрал gem (OnTriggerEnter с gem). Переход в idle — цель исчезла (gem подобрал другой враг) и новой нет. Переход в stun — скорость Rigidbody2D превысила порог входа.
[]2.10.3 moveToSpawn - Враг несёт gem к спавну. При входе в состояние gem выставляет isCarried = true, становится дочерним объектом врага. Переход в idle — достиг спавна, gem уничтожается (потерян). Переход в stun — скорость превысила порог, gem выпадает сразу (isCarried = false, открепить от врага).
[]2.10.4 stun - Враг не управляет собой, физика рулит. Переход обратно — скорость Rigidbody2D упала ниже нижнего порога И прошло минимальное время (0.5с). Возврат всегда в idle — пусть сам решит что делать заново.
[]2.10.5 dead - Финальный стейт, выхода нет. Входит когда Health.isDead = true. Дублирует флаг здоровья явным состоянием в AI — чтобы логика смерти была в одном месте. Вызывает Destroy(gameObject).

Условия победы и поражения
[]2.11 Скрипт Session. Следит за количеством драгоценностей на базе + на карте. Если сумма = 0 — поражение.
[]2.12 Победа: Session реактивно на смерть определяет если все враги уровня мертвы то победа.
[]2.13 Очки за уровень = количество оставшихся драгоценностей × 100. Вывести в Debug.Log при победе.
[]2.14 Создать минимальный UI: счётчик драгоценностей (число), счётчик оставшихся врагов (число). Два текстовых поля, никакого дизайна.
[]2.15 При победе или поражении — показать текст "WIN" или "LOSE" по центру экрана. Кнопка "Restart" перезапускает сцену через SceneManager.LoadScene.
Волны врагов
[]2.16 Сделать скрипт Map. У него массив ссылок на конфиги волн. В конфиге ссылки на префабы врагов, число и паузы.
[]2.17 Следующая волна спавнится по таймеру. Если осталось 0 живых и ещё есть волны — следующая спавнится досрочно.

Итерация 3 — Уровень и окружение
Карта деревни, статичные препятствия, интерактивные объекты (бочки, телеги). Первый играбельный уровень.
Статичное окружение

[]3.1 Создать префаб Wall: белый прямоугольник, Box Collider 2D, Rigidbody2D Static. Physics Material с небольшим bounce чтобы враги отлетали а не прилипали.
[]3.2 Создать префаб Rock: серый многоугольник, Polygon Collider 2D, Rigidbody2D Static. Форма неровная — враги отлетают под непредсказуемыми углами.
[]3.3 Создать префаб Fence: тонкий прямоугольник, Box Collider 2D Static. Обозначает границы деревни визуально.

Интерактивные объекты
[]3.4 Создать компонент Prop. Поля: float speedThreshold (порог скорости для нанесения урона), bool affectedByWave (реагирует ли на волну игрока). Вешается на все интерактивные объекты.
[]3.5 Создать префаб Barrel: тёмный круг, Rigidbody2D Dynamic (масса ~3), Circle Collider 2D, компонент Prop.
[]3.6 Создать префаб Cart: вытянутый прямоугольник, Rigidbody2D Dynamic (масса ~5), Box Collider 2D, компонент Prop.
[]3.7 Создать префаб Tree: круг, Rigidbody2D Static, компонент Prop (affectedByWave = false, speedThreshold высокий). При OnCollisionEnter2D с импульсом выше порога — переключается в Dynamic. После падения affectedByWave = true, speedThreshold снижается до обычного — работает как обычный Prop.
[]3.8 В скрипте врага при столкновении: GetComponent Prop на объекте с которым столкнулся. Если компонент есть и скорость выше Prop.speedThreshold — TakeDamage(1).

Структура карты
[]3.9 Создать ScriptableObject MapConfig. Поля: название уровня, массив конфигов волн.
[]3.10 Создать префаб карты Map. Внутри префаба расставить Treasury и EnemySpawner вручную. Скрипт Map хранит ссылки на них, собирает список в OnValidate.
